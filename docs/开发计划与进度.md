2. **预置任务**（4 个）：订单日统计（每日 01:05）、成本日统计（每日 01:10）、订单成本周统计（每周一 01:20）、订单成本月统计（每月 1 日 01:30）
3. **数据来源**（同实例跨库）：`genai_billing.billing_order`、`genai_costs.cost_daily`（缺失时回落 `genai_logs.usage_log` 明细）
4. **接口** `POST /api/scheduler/run-range?start=&end=` 支持任意区间手动补数
5. **网关接入**：启动即注册到服务发现；路由 `/gw/scheduler/** → StripPrefix=1 → PrefixPath=/api → 127.0.0.1:38097` 已写入 `sql/13`，重启 proxy 后生效
6. **实测**：区间 2026-10-25~11-07 统计结果 = 订单 5 笔 / 890.01 元，成本 472.95 元，请求 16662 次，Token 9029 万
