# SystemOne 判断模型服务（laya + nanojev） — 模块说明

- 服务 ID：`py-genai-rag-systemone`
- 端口：38109
- 代码来源：迁移自 ai-infer/py_laya_mlx + py_nano_jev（判断模型集合）
- 状态：模块化骨架完成；**暂不要求跑通/接入网关平台**（依赖缺失时服务可启动，`/health` 报告就绪状态）
- 调用链路角色：`调用方 → jv-genai-router(38100) → 本服务`；承接 studio-laya / studio-nanojev 判断模型（choice/score/boolean，RAG 流水线第④步）。详见项目 `docs/调用链路说明.md`

## 分层架构（对齐 Java Spring Boot 分包）

| Java 包 | Python 包 | 职责 |
|---------|----------|------|
| Application | `app/main.py` | 启动装配（create_app + lifespan + /health + /） |
| controller | `app/controller/` | 接口层（APIRouter） |
| service | `app/service/` | 业务编排 |
| loader | `app/engine/` | 模型加载与推理（继承公共 `py-genai-loadmodel.BaseModelEngine`） |
| mapper | `app/mapper/` | 外部资源访问（HTTP 客户端，无则为 —） |
| dto | `app/dto/` | pydantic 请求/响应模型 |
| config | `app/config/` | Settings 配置（支持环境变量覆盖） |
| common | `app/common/` | exceptions / gateway_report |

## 接口清单

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /v1/laya/decide | state/questions（choice/score/noul） | DecideResponse（MLX） |
| POST | /v1/laya/decide/batch | items[] | 串行批量决策 |
| POST | /v1/laya/route | 同 decide | 经 Router 语言路由后决策 |
| POST | /v1/nanojev/decide | states[]（多 state 合并前向） | DecideResponse（torch） |
| GET | /health、/v1/models、/v1/config | — | 两引擎 ready/load_error |

## 依赖说明

见根目录 `requirements.txt`（重依赖以注释列出，按需安装）；网关 SDK 暂不接入。
