# 向量生成服务（BGE-M3） — 启动与测试说明

## 启动

```bash
cd backend/py-genai-rag-embedding
./run.sh    # 等价：PYTHONPATH 追加 ../py-genai-loadmodel，uvicorn app.main:app --port 38103
```

- 首次运行安装基础依赖：`pip install -r requirements.txt`（fastapi/uvicorn/pydantic/httpx）
- 重依赖（torch/FlagEmbedding/transformers/laya-mlx 等）按 requirements.txt 注释按需安装；未安装时服务照常启动（降级模式）
- 验证：`curl http://localhost:38103/health`；接口索引：`curl http://localhost:38103/`

## 测试脚本（test/ 目录，中文命名）

| 脚本 | 说明 | 运行方式 |
|------|------|---------|
| 冒烟测试.py | /health、/v1/models、接口索引连通性 | `python3 test/冒烟测试.py` |
| 接口测试.py | 各路由正常/异常用例（400/503/404 断言） | `python3 test/接口测试.py` |
| 压力测试.py | 并发请求，统计成功率与 P50/P95 延迟 | `python3 test/压力测试.py [并发数] [请求数]` |
| 评估测试.py | 业务质量评估（黄金集/结构校验） | `python3 test/评估测试.py` |
| 运行全部.py | 依次执行以上四类并汇总 | `python3 test/运行全部.py` |

前置：服务已启动（默认 `http://localhost:38103`，可用环境变量 `BASE_URL` 覆盖）。
