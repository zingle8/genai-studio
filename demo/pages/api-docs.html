快速开始
三步发起第一次调用：① 在 API Key 页面创建密钥；② 配置 base_url 与密钥；③ 调用对话补全接口。
1. 准备凭据
密钥格式为 sk-<uuid>，例如 sk-9f2a7c4b-1e8d-4a3f-8c6e-5d2b0a7f3c1e；密钥同时有主键 ID kid=10048231，用于在日志与账单中定位调用来源。
2. 发起请求（cURL）
bash复制
curl https://api.ai-studio.local/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-9f2a7c4b-1e8d-4a3f-8c6e-5d2b0a7f3c1e" \
  -d '{
    "model": "DeepSeek-V3.2",
    "messages": [
      {"role": "system", "content": "你是一个严谨的技术助手。"},
      {"role": "user", "content": "用三句话解释什么是向量数据库"}
    ],
    "temperature": 0.7,
    "max_tokens": 1024
  }'
3. 发起请求（Python）
python复制
from openai import OpenAI

client = OpenAI(
    api_key="sk-9f2a7c4b-1e8d-4a3f-8c6e-5d2b0a7f3c1e",
    base_url="https://api.ai-studio.local/v1",
)

resp = client.chat.completions.create(
    model="DeepSeek-V3.2",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
鉴权
所有接口均需在请求头携带 Bearer Token。密钥仅在创建时展示一次，请妥善保存；泄露后请立即在控制台更新或删除。
Authorization: Bearer sk-xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx
Content-Type: application/json
密钥能力
配置项说明示例
可用模型不限制或指定模型白名单，未授权的模型返回 403模型不限制
过期时间永久有效或指定日期，过期前 7 天自动提醒创建人2027-10-10
限流 RPM每分钟请求数上限，不限制则继承账号默认额度3000
限流 TPM每分钟 Token 上限（输入 + 输出）1000000
并发上限同时在途请求数，超出后排队或快速失败500
IP 白名单CIDR 限制调用来源，留空表示不限制10.0.0.0/8
对话补全
POST/v1/chat/completions
请求参数
参数类型必填说明
modelstring是模型名称，如 DeepSeek-V3.2、GLM-4.7、GPT-4o
messagesarray是消息列表，role 支持 system / user / assistant / tool
streamboolean否是否流式返回，默认 false
temperaturenumber否采样温度 0~2，默认 1；越低越确定
max_tokensinteger否生成上限，默认取模型最大输出长度
top_pnumber否核采样，与 temperature 建议只调一个
toolsarray否函数调用工具定义，见「函数调用」
response_formatobject否设为 {"type":"json_object"} 强制输出 JSON
响应示例
{
  "id": "chatcmpl-8f2a71c4b9e3",
  "object": "chat.completion",
  "created": 1791187385,
  "model": "DeepSeek-V3.2",
  "choices": [
    {
      "index": 0,
      "message": {"role": "assistant", "content": "向量数据库是专门存储和检索高维向量的数据库…"},
      "finish_reason": "stop"
    }
  ],
  "usage": {"prompt_tokens": 32, "completion_tokens": 118, "total_tokens": 150}

视觉理解（多模态）
POST/v1/chat/completions · 支持 GLM-4V、GLM-4V-Flash、GPT-4o、Claude 3.5。
图片通过 content 数组传入，与文本混排。支持两种形式：公网图片链接（推荐，无需上传）与 Base64 内联（本地图片，格式 data:image/jpeg;base64,<编码>）。
方式一：图片 URL
python复制
resp = client.chat.completions.create(
    model="GLM-4V",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "这张图里有哪些设备？请列出并说明位置"},
            {"type": "image_url", "image_url": {"url": "https://example.com/rack.jpg"}},
        ],
    }],
)
print(resp.choices[0].message.content)
方式二：Base64 内联
python复制
import base64

with open("rack.jpg", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()

resp = client.chat.completions.create(
    model="GLM-4V",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image_url",
             "image_url": {"url": f"data:image/jpeg;base64,{b64}"}},
            {"type": "text", "text": "识别图中告警指示灯"},
        ],
    }],
)
图片限制与计费
项目限制 / 规则
支持格式JPEG / PNG / WEBP / GIF（静态）
单图大小≤ 10 MB；Base64 后体积约为原图 1.33 倍
单次请求图片数≤ 8 张
分辨率建议长边 ≤ 2048px，超出会自动等比压缩
Token 折算图片按 ⌈长 × 宽 / 750⌉ 折算为视觉 Token，计入 prompt_tokens
计价方式视觉 Token 按对应模型的输入价计费，详见产品定价页
提示：多轮对话中重复传同一张图会重复计费，建议将图片结论写入后续文本上下文。
流式输出
设置 stream: true，服务端以 SSE（text/event-stream）逐块返回增量内容，适合打字机效果。流结束后返回 data: [DONE]。
bash复制
curl https://api.ai-studio.local/v1/chat/completions \
  -H "Authorization: Bearer $AI_STUDIO_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"DeepSeek-V3.2","stream":true,
       "messages":[{"role":"user","content":"写一首关于白露的五言诗"}]}'
SSE 响应
data: {"choices":[{"delta":{"content":"白"}}]}
data: {"choices":[{"delta":{"content":"露"}}]}
data: {"choices":[{"delta":{"content":"凝"}}]}
data: {"choices":[{"delta":{},"finish_reason":"stop"}],"usage":{"total_tokens":96}}
data: [DONE]
流式与非流式计费一致；异常中断时已产生的 Token 仍会计费。
函数调用（Tool Calling）
在 tools 中声明可调用函数，模型会返回 tool_calls；执行本地函数后以 role: "tool" 回传结果。
python复制
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询指定城市的实时天气",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string", "description": "城市名"}},
            "required": ["city"],
        },
    },
}]

resp = client.chat.completions.create(
    model="GLM-4.7",
    messages=[{"role": "user", "content": "杭州今天要带伞吗？"}],
    tools=tools,
    tool_choice="auto",
)
print(resp.choices[0].message.tool_calls)
向量化
POST/v1/embeddings · 用于知识库入库与语义检索，输出维度与模型相关（GLM-Embedding-3 为 2048 维）。
{
  "model": "GLM-Embedding-3",
  "input": ["向量数据库选型对比", "如何提升 RAG 召回率"]
}
响应（截断）
{
  "data": [
    {"index": 0, "embedding": [0.0123, -0.0456, 0.0789, "…"]},
    {"index": 1, "embedding": [-0.0331, 0.0902, 0.0145, "…"]}
  ],
  "usage": {"prompt_tokens": 18, "total_tokens": 18}
}
单次最多 64 条文本，每条 ≤ 8192 Token；批量请求按总 Token 计费。
速率限制
限流按 API Key 维度生效，可在创建/更新密钥时配置为「不限制」或指定数值；未配置则继承账号默认额度（3000 RPM / 1M TPM / 500 并发）。
维度含义超限返回建议处理
RPM每分钟请求数429指数退避重试（1s → 2s → 4s）
TPM每分钟 Token 数（输入 + 输出）429缩短上下文或分批提交
并发同时在途请求数429 / 排队降低客户端并发，或申请提额
响应头会返回 x-ratelimit-limit-requests、x-ratelimit-remaining-tokens、retry-after，可用于自适应节流。提额入口：运维中心 / 提交工单。
错误码
HTTP错误码说明处理建议
400invalid_request_error参数缺失或格式错误对照请求参数表检查字段与类型
401invalid_api_key密钥无效、已删除或格式错误确认 Header 中 Bearer 后为完整 sk- 密钥
402insufficient_balance账户余额不足前往 充值
403model_not_allowed调用的模型不在密钥白名单内更新密钥可用模型范围
404model_not_found模型不存在或已下线在模型广场确认名称
413payload_too_large请求体超限（含 Base64 图片）压缩图片或改用图片 URL
422context_length_exceeded上下文超出模型窗口裁剪历史消息或改用长上下文模型
429rate_limit_exceeded触发 RPM / TPM / 并发限制退避重试或申请提额
500internal_error服务端异常重试；持续失败提交工单
503upstream_unavailable上游模型不可用或已摘流切换备用模型，见运维中心告警
错误响应体
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Rate limit reached for RPM: Limit 3000, Used 3000.",
    "type": "requests"
  }
}
