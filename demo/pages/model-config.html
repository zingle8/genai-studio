from openai import OpenAI

# 平台网关兼容 OpenAI 协议，替换 base_url 即可复用现有代码
client = OpenAI(
    api_key="sk-xxxxxxxxxxxxxxxx",
    base_url="https://api.ai-studio.example.com/v1",
)

resp = client.chat.completions.create(
    model="glm-5.3-prod",                    # 模型管理中的配置名称
    messages=[{"role": "user", "content": "你好，介绍一下你自己"}],
)
print(resp.choices[0].message.content)

max_tokensinteger—最大输出 token 数，不得超过模型配置的最大输出
toolsarray—工具 / 函数调用定义（OpenAI function calling 格式）
userstring—终端用户标识，用于计费分摊与审计追溯

错误码与限流
4xx 请检查请求；5xx 由网关自动按降级链重试，无需客户端处理
HTTPerror.type说明与处理建议
400invalid_request_error参数缺失或格式错误，检查 model 名称与消息结构
401authentication_errorAPI Key 无效或已禁用；前往开发者中心重新获取
403permission_deniedKey 未授权该模型；敏感模型仅允许中国区 Key 调用
404model_not_found模型不存在或已被管理员禁用
429rate_limit_exceeded触发 RPM / TPM / 并发限流；按 Retry-After 退避重试
5xxupstream_error上游异常，网关已自动切换降级模型；持续出现请联系平台管理员
限流响应头 每个响应均携带，便于客户端自适应退避
X-RateLimit-Limit-RPM:      3000        # Key 的 RPM 上限（模型配置中的限流值）
X-RateLimit-Remaining-RPM:  2871        # 当前窗口剩余次数
X-RateLimit-Reset-At:       1760102400  # 窗口重置时间（Unix 秒）
X-Request-Id:               req-8a1f33c2  # 全链路追踪 ID，排障必带
