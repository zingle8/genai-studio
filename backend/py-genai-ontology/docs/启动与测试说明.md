# 启动与测试说明 — py-genai-ontology

## 启动
```bash
cd py-genai-ontology
./run.sh          # uvicorn app.main:app --host 0.0.0.0 --reload --port 38105
```
- 首次启动自动建表（`tb_onto_space` 等 6 张）并执行存量空间迁移。
- 网关注册失败不阻塞启动（仅日志告警）。

## 健康检查
```bash
curl http://localhost:38105/health
# {"service":"py-genai-ontology","status":"ok"}
```

## 测试（手写 HTTP 断言脚本，前置：服务已启动）
```bash
python3 test/冒烟测试.py     # /health、空间/本体/数据源列表连通性
python3 test/接口测试.py     # 空间/本体/类/关系/导入导出/检查 全链路 + 异常分支断言
python3 test/运行全部.py     # 依次执行以上用例并汇总退出码
```
- 可用 `BASE_URL=http://其他地址:端口` 覆盖默认 `http://localhost:38105`。
- 接口测试自清理数据（创建的测试空间/本体最后删除）。

## 目录结构
见 `docs/包与文件说明.md`；分层与 `py-genai-rag-reranker` 对齐：
controller(接口) / service(业务) / mapper(数据) / dto / config / common。
