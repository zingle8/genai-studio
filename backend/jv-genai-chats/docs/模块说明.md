# 体验中心会话服务 — 模块说明

- 服务 ID：`jv-genai-chats`
- 端口：38090
- 定位：体验中心的**会话与消息存储服务**（不管推理）——推理由前端直连 jv-genai-router，推理完成后前端调用本服务批量落库
- 状态：已实现并实测（批量落库、轮次 trace 查询、按日分区）

## 调用链路角色

```
fe-chats(38202) ──推理──→ jv-genai-router(38100)     ← 本服务不在推理链路
fe-chats(38202) ──落库──→ 本服务(38090)              ← 会话/消息存储
```

与 py-genai-infer 等执行器互不调用；职责分离详见项目根 `docs/调用链路说明.md`。

## 数据模型（三层区分）

```
会话 tb_chat_session          （多会话）
  └ 轮次 trace_id             （用户输入一次问题 = 1 轮；1 条 user + N 个模型回复共用同一 trace）
      └ 消息 tb_chat_message  （assistant 带 model 字段区分多模型并发回复；按日 RANGE 分区）
```

- `tb_chat_message`：RANGE(TO_DAYS(created_at)) 按日分区，存储过程 `sp_add_chat_msg_partition` + 每日事件滚动新分区
- 消息列：role / content / model / trace_id / prompt_tokens / completion_tokens / cost / created_at

## 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/chats | 会话分页列表 |
| POST | /api/chats | 创建会话（体验中心首次发送时自动创建，标题取首句前 20 字） |
| PUT/DELETE | /api/chats/{id} | 重命名 / 删除 |
| GET | /api/chats/{id}/messages | 历史还原（含 model/trace_id/tokens/cost） |
| POST | /api/chats/{id}/messages/batch | 批量落库一轮（user + N 模型回复，同 trace_id） |
| GET | /api/chats/{id}/trace/{traceId} | 按轮次精确回放（该问题 + 各模型回复） |
