# 包与文件说明 — py-genai-graph

```
py-genai-graph/
├── run.sh                              # 启动脚本（uvicorn app.main:app --port 38107）
├── requirements.txt                    # fastapi / uvicorn / pydantic / httpx + apigateway-sdk
├── graph.db                            # SQLite 数据文件（可用 GRAPH_DB 环境变量覆盖）
├── app/
│   ├── main.py                         # 入口：create_app() 装配 service=GraphServiceImpl + CORS + 网关
│   ├── controller/
│   │   └── graph_controller.py         # 接口层：create_routers(service) 注册全部 /api/graphs/* 路由
│   ├── service/
│   │   ├── graph_service.py            # 业务接口契约（abc.ABC 抽象方法清单）
│   │   └── impl/
│   │       └── graph_service_impl.py   # 业务实现：空间/图谱/实体/节点/边/邻域/版本
│   ├── mapper/
│   │   └── graph_mapper.py             # 数据访问：sqlite 内置存储 + neo4j HTTP API 双后端
│   ├── dto/
│   │   └── graph_dto.py                # 请求模型：SpaceIn/GraphIn/EntityIn/NodeIn/EdgeIn/VersionIn
│   ├── config/
│   │   └── settings.py                 # 服务配置：service_id/网关地址/db_path（env 可覆盖）
│   └── common/
│       └── gateway_report.py           # 网关平台适配单例 gateway_report
├── test/                               # 手写 HTTP 断言脚本（python3 test/xxx.py）
│   ├── 冒烟测试.py
│   ├── 接口测试.py
│   └── 运行全部.py
└── docs/                               # 本目录文档
```

## 依赖注入方式
`main.create_app()` 内 `service = GraphServiceImpl()`，`app.include_router(create_routers(service))`；
controller 工厂闭包捕获 service 实例。

## 环境变量
| 变量 | 默认 | 说明 |
|---|---|---|
| `GRAPH_DB` | `<模块根>/graph.db` | SQLite 路径 |
| `GATEWAY_SERVER_ADDR` | `http://127.0.0.1:28090/api` | 网关上报地址 |
| `GATEWAY_CLIENT_TOKEN` | `dev-gateway-token` | 网关接入 Token |
