# 模块说明 — py-genai-ontology（本体知识服务）

## 基本信息
| 项 | 值 |
|---|---|
| 服务 ID | `py-genai-ontology` |
| 服务名 | 本体知识服务 |
| 端口 | 38105 |
| 启动 | `./run.sh`（`uvicorn app.main:app --port 38105`） |
| 存储 | SQLite `onto.db`（内置） |
| 网关接入 | py-genai-apigateway-client-sdk（注册/心跳/指标/请求采集） |
| 图数据源 | `builtin-demo` 内置示例 / `graph-ref` 引用图谱模块实例数据 |

## 职责
- **本体空间**：本体必须归属空间（对齐知识库空间模型），空间非空禁删。
- **本体管理**：本体（领域/个人、命名空间、权威级）CRUD 与全量详情。
- **类 / 关系规则 / 映射**：类的父子层级、关系规则（主语类→宾语类、基数 one/many、可空、继承）、本体类型↔物理类型映射。
- **导入导出**：Turtle（TTL）与 YAML 双格式 DSL 解析与导出（`app/common/onto_parser.py`）。
- **一致性检查**：`check_ontology(oid)` 规则校验（`app/common/onto_checker.py`）。
- **图数据源**：数据源登记 + 内置示例公司数据 + 本体视图投影（按映射过滤节点/边类型）。

## 数据表
`tb_onto_space` / `tb_ontology`（含 space_id） / `tb_onto_class` / `tb_onto_rel` / `tb_onto_mapping` / `tb_data_source`

## 接口清单
| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/onto/spaces` | 空间列表（含 onto_count）/ 创建 |
| DELETE | `/api/onto/spaces/{sid}` | 删除空间（非空 400） |
| GET/POST | `/api/onto/ontologies` | 本体列表 / 创建 |
| PUT/DELETE | `/api/onto/ontologies/{oid}` | 更新 / 删除（级联清理） |
| GET | `/api/onto/{oid}/full` | 全量详情（本体+类+关系+映射） |
| POST/PUT/DELETE | `/api/onto/classes*` | 类 CRUD（同名类 400） |
| POST/PUT/DELETE | `/api/onto/rels*` | 关系规则 CRUD（重复规则 400） |
| POST/DELETE | `/api/onto/mappings*` | 映射增删 |
| POST | `/api/onto/import` | 导入（format=ttl/yaml） |
| GET | `/api/onto/{oid}/export?format=` | 导出（ttl/yaml） |
| GET | `/api/onto/{oid}/check` | 一致性检查 |
| GET | `/api/onto/{oid}/versions` | 版本快照列表（类/关系/映射每次写入自动快照） |
| GET | `/api/onto/{oid}/versions/{no}` | 版本详情（含快照内容） |
| POST | `/api/onto/{oid}/versions/{no}/restore` | 恢复版本（恢复前自动存一版） |
| GET | `/api/onto/audit?oid=&limit=` | 审计日志（oid 省略=全部） |
| GET/POST | `/api/onto/datasources` | 数据源列表 / 登记 |
| GET | `/api/onto/graph-data?ds=` | 图数据（内置示例） |
| GET | `/api/onto/{oid}/view-graph` | 本体视图投影 |
| GET | `/health` | 健康检查 |
