# 模型路由网关 — 模块说明

- 服务 ID：`jv-genai-router`
- 端口：38100
- 定位：**平台唯一模型转发收口**——所有模型推理（外部云端 / 本地 py 执行器 / Ollama）统一经本模块转发；鉴权、限流、余额、计费、日志只在此做一次
- 状态：已实现并实测（校验链、Redis+MySQL 双写限流、tier 计费、双日志 trace 对齐）

## 调用链路角色

```
调用方（fe-chats 体验中心 / 外部 SDK / 未来知识库编排）
   ↓ POST /v1/**（Bearer API Key，body.model 填平台名）
本模块：每请求实时查 tb_model_info 动态转发 → 各执行器/云端/Ollama
   ↓ 响应原路透传 + 事后计费/日志
```

详见项目根 `docs/调用链路说明.md`（四条链路、校验链、trace 对齐）。

## 分层架构

| 层 | 类 | 职责 |
|----|----|------|
| controller | RelayController | 转发主流程：读体解析 model → 校验链 → 转发 → 透传 → 计费/日志（流式边透传边收集 usage）；`base_url` 逗号分隔多实例时 `pickBaseUrl()` 原子轮询（round-robin）分发，单地址向后兼容 |
| controller | ModelListController | `GET /v1/models`（裸 OpenAI 格式直读库）、`GET /v1/me`（Key 自检） |
| service | RelayGuardService | 校验链与记账：鉴权 / 限流 / 余额 / 扣费 / usage_log + relay_log（trace_id 同源对齐） |
| service | RedisRateLimitStore | 限流 Redis 存储（双写 Redis+MySQL；Redis 故障熔断 30s 降级 MySQL） |
| service | GuardException | 校验链异常（status + message，OpenAI error 格式输出） |
| entity/mapper | ModelEntity / RouterModelMapper | tb_model_info 路由视图（跨库只读） |
| entity/mapper | ApiKeyEntity / RelayGuardMapper | tb_api_key 鉴权视图 + 限流计数 + 余额 + 定价 + usage/cost 写入 |
| mapper | RelayLogMapper | tb_relay_log 请求/回复内容日志（按日分区） |

## 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /v1/**、/chat/completions 等 | 动态转发（/v1/chat/completions、/v1/embeddings、/v1/rerank、/v1/laya/decide、/v1/nanojev/decide…按模型 url_paths 白名单） |
| GET | /v1/models | 平台模型列表（裸 OpenAI 格式 + jv-* 扩展字段：real-model/base-url/tier/api-format/category） |
| GET | /v1/me | 当前 API Key 自检（name/key_id/models 白名单/rpm/tpm/cc） |

## 转发前校验链与事后记账

```
转发前：① tb_api_key 鉴权(401/403) → ② RPM/TPM/CC 限流(429) → ③ tb_account_balance 余额(402)
转发后：④ tier 单价(tb_model_price) × tokens 扣费 → ⑤ tb_usage_log + tb_relay_log（trace_id 对齐）
错误统一 OpenAI error 格式；记账失败仅告警不影响响应
```
