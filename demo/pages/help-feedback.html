账号与计费
如何获取 API Key？
在 API Key 页面点击「创建 API Key」，指定可用模型、过期时间、限流与并发额度后生成。密钥格式为 sk-<uuid>，仅在创建成功时完整展示一次，请立即保存到密钥管理服务中。
费用是怎么计算的？
按 Token 计费，输入与输出分别计价，多模态图片按 ⌈长 × 宽 / 750⌉ 折算为视觉 Token 计入输入。每笔调用可在使用日志查看明细，在成本统计查看聚合报表。
余额不足会怎样？如何设置提醒？
余额为 0 时调用会返回 402 insufficient_balance，已产生的费用不受影响。可在用户中心 → 用量信息开启余额预警（默认阈值 ¥50 / ¥10），触发后通过站内信与邮件提醒创建人。
可以开发票吗？支持哪些类型？
支持增值税普通发票（电子）与专用发票。进入账单页面选择账期后点击「开发票」；企业认证用户可开具专票，一般 1~3 个工作日寄出。
接口与调用
返回 429 限流错误怎么处理？
说明触发了 RPM / TPM / 并发限制。建议：① 客户端指数退避重试（1s → 2s → 4s）；② 读取响应头 retry-after 与 x-ratelimit-remaining-tokens 自适应节流；③ 在 API Key 配置中调高限流值或在工单申请提额。
是否兼容 OpenAI SDK？
兼容。只需将 base_url 指向 https://api.ai-studio.local/v1、api_key 换成平台密钥即可，chat.completions、embeddings、流式与 tools 均可直接使用，详见接口文档。
上下文长度超限（422）怎么办？
先确认模型上下文窗口（模型广场可查），再裁剪历史消息或压缩长文本；知识密集型场景建议改用 RAG 检索注入，而非全量拼接。
流式输出计费和非流式一样吗？
一致，均按实际输入输出 Token 计费。若客户端中途断开，已生成的 Token 仍会计费。
模型与能力
如何选择模型？对标关系是什么？
通用对话选 DeepSeek-V3.2（性价比高）；复杂推理与数学选 DeepSeek-R1；多模态看图选 GLM-4V；向量化选 GLM-Embedding-3；需要极致稳定与英文场景可选 GPT-4o / Claude 3.5。可用模型广场的对比视图横向评估。
知识库文档解析失败怎么排查？
常见原因：① 扫描件 PDF 未 OCR（请开启 OCR 解析）；② 单文件超 100 MB 或页数超 1000；③ 加密文档需先去密。解析失败详情可在知识库的文档列表查看错误日志。
RAG 召回效果差，如何优化？
建议调优顺序：① 提高切片质量（按语义分块而非固定长度）；② 调整 top-k（默认 8，可试 5/12）；③ 开启重排序（Rerank）模型；④ 对专业名词补充同义词表；⑤ 用「命中率 / 引用准确率」在RAG 管理的回放评测中量化验证。
数据会被用于模型训练吗？
不会。平台默认对所有请求与知识库数据不用于训练，传输全程 TLS 加密，存储支持静态加密；可在平台配置 → 安全与合规中调整日志保留周期。
