# 检索增强服务 — 模块说明

- 服务 ID：`py-genai-rag`
- 端口：38102
- 代码来源：按 ai-infer/py_rag 技术文档设计的编排层（源项目无代码）
- 状态：模块化骨架完成；**暂不要求跑通/接入网关平台**（依赖缺失时服务可启动，`/health` 报告就绪状态）

## 分层架构（对齐 Java Spring Boot 分包）

| Java 包 | Python 包 | 职责 |
|---------|----------|------|
| Application | `app/main.py` | 启动装配（create_app + lifespan + /health + /） |
| controller | `app/controller/` | 接口层（APIRouter） |
| service | `app/service/` | 业务编排 |
| loader | `app/engine/` | 模型加载与推理（继承公共 `py-genai-loadmodel.BaseModelEngine`） |
| mapper | `app/mapper/` | 外部资源访问（HTTP 客户端，无则为 —） |
| dto | `app/dto/` | pydantic 请求/响应模型 |
| config | `app/config/` | Settings 配置（支持环境变量覆盖） |
| common | `app/common/` | exceptions / gateway_report |

## 接口清单

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /v1/chunk | document/chunk_size/overlap/metadata | 切片列表 {index,text,start} |
| POST | /v1/retrieve | query/documents/top_k/top_n | 重排结果 + 组装 context |

## 依赖说明

见根目录 `requirements.txt`（重依赖以注释列出，按需安装）；网关 SDK 暂不接入。
