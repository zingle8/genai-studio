# 向量生成服务（BGE-M3） — 业务逻辑说明

1. 启动 lifespan 调 engine.load()：BGEM3FlagModel 加载（mps→bf16 / cuda→fp16），失败降级不阻塞
2. encode()：RLock 串行，一次前向产出 dense/sparse/colbert
3. 输出转换：dense→float 列表或 base64（dimensions 截断）；sparse→{indices,values} 降序 topk；colbert→token×1024 矩阵
4. 异常翻译：ModelNotLoadedError → 503 / ValueError → 400
5. 攒批调度器为后续优化项（见 ai-infer embedding_batch_scheduler.py）

## 公共 loading 机制

引擎均继承 `backend/py-genai-loadmodel/loadmodel/base_engine.py` 的 `BaseModelEngine`：

- `load()`：幂等（重复调用直接返回）、加锁、计时（load_seconds）、异常降级（依赖/权重缺失仅记录 load_error，不阻塞服务启动）
- `inference_lock()`：推理互斥（模型推理串行执行）
- `describe()`：统一状态字段（model/backend/ready/device/load_seconds/load_error），health 与 config 接口复用
- `pick_device()`：auto → cuda / mps / cpu 自动选择
