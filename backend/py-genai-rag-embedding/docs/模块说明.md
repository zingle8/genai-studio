# 向量生成服务（BGE-M3） — 模块说明

- 服务 ID：`py-genai-rag-embedding`
- 端口：38103
- 代码来源：迁移自 ai-infer/py_embedding（精简版）
- 状态：模块化骨架完成；**暂不要求跑通/接入网关平台**（依赖缺失时服务可启动，`/health` 报告就绪状态）
- 调用链路角色：`调用方 → jv-genai-router(38100) → 本服务`；承接 studio-embedding 模型的向量化（RAG 流水线第①步）。详见项目 `docs/调用链路说明.md`

## 分层架构（对齐 Java Spring Boot 分包）

| Java 包 | Python 包 | 职责 |
|---------|----------|------|
| Application | `app/main.py` | 启动装配（create_app + lifespan + /health + /） |
| controller | `app/controller/` | 接口层（APIRouter） |
| service | `app/service/` | 业务编排 |
| loader | `app/engine/` | 模型加载与推理（继承公共 `py-genai-loadmodel.BaseModelEngine`） |
| mapper | `app/mapper/` | 外部资源访问（HTTP 客户端，无则为 —） |
| dto | `app/dto/` | pydantic 请求/响应模型 |
| config | `app/config/` | Settings 配置（支持环境变量覆盖） |
| common | `app/common/` | exceptions / gateway_report |

## 接口清单

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /v1/embeddings | input/model + InferenceParams | OpenAI 兼容 dense 向量 |
| POST | /v1/sparse_embeddings | 同上 | SPLADE 风格 {indices,values} |
| POST | /v1/colbert_embeddings | 同上 | token 级向量矩阵 |
| POST | /v1/hybrid_embeddings | + return_dense/sparse/colbert | 三件套任选组合 |
| GET | /v1/models、/v1/config | — | 模型/设备/维度状态 |

## 依赖说明

见根目录 `requirements.txt`（重依赖以注释列出，按需安装）；网关 SDK 暂不接入。
