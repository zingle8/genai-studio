# 推理服务 — 模块说明

- 服务 ID：`py-genai-infer`
- 端口：38101
- 代码来源：本地普通生成模型的加载与推理执行器；统一转发收敛到 jv-genai-router
- 状态：模块化骨架完成；**暂不要求跑通/接入网关平台**（依赖缺失时服务可启动，`/health` 报告就绪状态）
- 调用链路角色：`调用方 → jv-genai-router(38100) → 本服务`；仅承接 studio-chat 模型的本地推理，不做转发（转发统一收口 router）。详见项目 `docs/调用链路说明.md`

## 分层架构（对齐 Java Spring Boot 分包）

| Java 包 | Python 包 | 职责 |
|---------|----------|------|
| Application | `app/main.py` | 启动装配（create_app + lifespan + /health + /） |
| controller | `app/controller/` | 接口层（APIRouter） |
| service | `app/service/` | 业务编排 |
| loader | `app/engine/` | 模型加载与推理（继承公共 `py-genai-loadmodel.BaseModelEngine`） |
| mapper | `app/mapper/` | OpenAI 兼容响应组装（转发统一由 jv-genai-router 负责） |
| dto | `app/dto/` | pydantic 请求/响应模型 |
| config | `app/config/` | Settings 配置（支持环境变量覆盖） |
| common | `app/common/` | exceptions / gateway_report |

## 接口清单

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /v1/chat/completions | messages/temperature/max_tokens | OpenAI 兼容对话响应 |
| POST | /chat/completions | 同上（无前缀别名） | 同上 |
| GET | /v1/models | — | 本地模型模式与就绪状态 |
| GET | /v1/config | — | 引擎模式/上游地址/加载状态 |
