# 向量生成服务（BGE-M3） — 压力测试报告

> 测试工具：`test/压力测试.py`（stdlib urllib + 线程池，无额外依赖）
> 当前状态：**骨架阶段**，以下为测试方案与指标框架；结果区待服务依赖安装后实测填充。

## 一、测试方案

- 对象：GET /health（轻）、批量文本 encode 吞吐（条/秒）、并发请求排队延迟 P50/P95
- 方式：线程池并发，采样成功率 / P50 / P95 / P99 延迟
- 档位：并发 1 / 4 / 16 / 32，每档 100 请求

## 二、指标基线（预期）

| 指标 | 基线 |
|------|------|
| /health 成功率 | ≥ 99.9% |
| /health P95（本机） | ≤ 50 ms |
| 业务接口 P95（模型就绪） | 待实测（视模型与设备） |
| 错误率 | ≤ 0.1%（不含模型未加载导致的 503 降级） |

## 四、结论与建议

1. 引擎未加载时业务接口返回 503 属预期降级，不计入错误率
2. 模型就绪后的推理压测需在目标设备（MPS/CUDA）上单独执行
3. 高吞吐场景建议接入攒批调度（参考 ai-infer embedding_batch_scheduler.py）
