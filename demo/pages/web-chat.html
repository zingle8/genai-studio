知识库召回的答案经常不全，有什么优化思路？
AI Studio 助手·DeepSeek-V3.2

建议按「切片 → 召回 → 精排 → 生成」四段逐一排查：

  • 切片：按语义 / 标题分块，避免固定长度切断表格与代码；块重叠 10%~15%。
  • 召回：top-k 从 8 提到 12，并开启混合检索（向量 + 关键词）。
  • 精排：加一层 Rerank 模型，典型可提升 10~20 个百分点的命中准确率。
  • 生成：提示词中强制「仅依据引用片段回答，无依据时说明不确定」。

可直接用下面的分块示例改造入库流程：

python 
def split(text, size=512, overlap=64):
    step = size - overlap
    return [text[i:i + size] for i in range(0, len(text), step)]
