# 模块说明 — py-genai-graph（知识图谱服务）

## 基本信息
| 项 | 值 |
|---|---|
| 服务 ID | `py-genai-graph` |
| 服务名 | 知识图谱服务 |
| 端口 | 38107 |
| 启动 | `./run.sh`（`uvicorn app.main:app --port 38107`） |
| 存储 | SQLite `graph.db`（内置）或 Neo4j（图谱级 db_config，HTTP API 读写） |
| 网关接入 | py-genai-apigateway-client-sdk（注册/心跳/指标/请求采集） |

## 职责
- **图谱空间**：图谱必须归属空间（`tb_graph_space`，对齐知识库空间模型），空间非空禁删。
- **图谱管理**：图谱（数据库概念）CRUD，逐图选择存储后端 sqlite/neo4j。
- **实体类型**：实体类型与属性定义（props_schema）。
- **节点与属性 / 关系**：节点 CRUD、关系（source→target + rel_type）CRUD。
- **邻域查询**：以多节点为起点按深度 1~7 层展开子图。
- **版本管理**：版本号（v1→v2…）+ 节点/关系变更自动快照，支持版本列表/详情/恢复。
- **审计日志**：全部写操作记录操作人/时间/对象/详情，操作人取自 JWT。

## 接口清单
| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/graphs/spaces` | 空间列表 / 创建 |
| DELETE | `/api/graphs/spaces/{sid}` | 删除空间（非空 400） |
| GET/POST | `/api/graphs` | 图谱列表 / 创建 |
| PUT/DELETE | `/api/graphs/{gid}` | 更新 / 删除 |
| GET/POST | `/api/graphs/{gid}/entities` | 实体类型列表 / 新增 |
| PUT/DELETE | `/api/graphs/{gid}/entities*` | 实体类型修改 / 删除 |
| GET/POST | `/api/graphs/{gid}/nodes` | 节点列表 / 新增 |
| PUT/DELETE | `/api/graphs/{gid}/nodes*` | 节点修改 / 删除 |
| GET/POST | `/api/graphs/{gid}/edges` | 关系列表 / 新增 |
| DELETE | `/api/graphs/{gid}/edges*` | 关系删除 |
| GET | `/api/graphs/{gid}/neighborhood?nids=1,2&depth=1..7` | 多起点邻域子图（兼容旧 nid） |
| GET | `/api/graphs/{gid}/versions` | 版本列表 |
| GET | `/api/graphs/{gid}/versions/{vid}/detail` | 版本详情 |
| POST | `/api/graphs/{gid}/versions/{vid}/restore` | 恢复版本 |
| GET | `/api/graphs/audit?gid=&limit=` | 审计日志（gid 省略=全部） |
| GET | `/health` | 健康检查 |
