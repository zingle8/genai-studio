# 包与文件说明 — py-genai-ontology

```
py-genai-ontology/
├── run.sh                        # 启动脚本（uvicorn app.main:app --port 38105）
├── requirements.txt              # fastapi / uvicorn / pydantic / pyyaml + apigateway-sdk
├── onto.db                       # SQLite 数据文件（可用 ONTO_DB 环境变量覆盖）
├── app/
│   ├── main.py                   # 入口：create_app() 装配 controller/service/mapper，/health 与 / 索引
│   ├── controller/
│   │   └── onto_controller.py    # 接口层：create_routers(service) 注册全部 /api/onto/* 路由
│   ├── service/
│   │   └── onto_service.py       # 业务层：空间/本体/类/关系/映射/导入导出/检查/数据源 全部业务函数
│   ├── mapper/
│   │   └── onto_mapper.py        # 数据层：SQLite 连接与 rows/run/one/exec_many，建表与存量迁移
│   ├── dto/
│   │   └── onto_dto.py           # 请求模型：OntoIn/SpaceIn/ClassIn/RelIn/MapIn/ImportIn
│   ├── config/
│   │   └── settings.py           # 服务配置：service_id/网关地址/Token（env 可覆盖）
│   └── common/
│       ├── gateway_report.py     # 网关平台适配单例 gateway_report（注册/心跳/采集/下线）
│       ├── onto_parser.py        # DSL 解析：parse_ttl/parse_yaml/to_ttl/to_yaml
│       └── onto_checker.py       # 一致性检查：check_ontology(oid)
├── test/                         # 手写 HTTP 断言脚本（python3 test/xxx.py）
│   ├── 冒烟测试.py
│   ├── 接口测试.py
│   └── 运行全部.py
└── docs/                         # 本目录文档
```

## 依赖注入方式
`main.create_app()` 内 `from app.service import onto_service` 后调用
`app.include_router(create_routers(onto_service))`；controller 闭包捕获 service（模块级函数集合）。

## 环境变量
| 变量 | 默认 | 说明 |
|---|---|---|
| `ONTO_DB` | `<模块根>/onto.db` | SQLite 路径 |
| `GATEWAY_SERVER_ADDR` | `http://127.0.0.1:28090/api` | 网关上报地址 |
| `GATEWAY_CLIENT_TOKEN` | `dev-gateway-token` | 网关接入 Token |
